# Recursos visuales

La portada usa `blog_cover.jpg`, fotografía descargada desde Unsplash:

https://images.unsplash.com/photo-1455390582262-044cdead277a

La imagen se incluye como recurso local para que la portada no dependa de una descarga externa al abrir la app. Las fotografías de publicaciones siguen siendo URLs guardadas en MySQL.

La página https://www.blogger.com/about/ se utilizó como referencia de composición y colores cálidos. No se utiliza el logotipo de Blogger ni se presenta esta aplicación como un producto de Google.
